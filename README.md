## 🚀 Deploy to Vercel (Free) — Step by Step

### Option A: Drag & Drop (Easiest — no coding needed)

1. Go to **https://vercel.com** and create a free account (use GitHub or Google login)
2. From your dashboard click **"Add New → Project"**
3. Choose **"Import from your computer"** or drag the `portfolio` folder
4. Vercel auto-detects it as a static site
5. Click **"Deploy"** — done in 30 seconds!
6. You get a free URL like: `kamaleshvar-portfolio.vercel.app`

### Option B: Via GitHub (Recommended for easy updates)

1. Create a free account at **https://github.com**
2. Create a new repo called `portfolio` (set to Public)
3. Upload `index.html` and `vercel.json` into the repo
4. Go to **https://vercel.com** → "Add New → Project"
5. Click **"Import from GitHub"** → select your `portfolio` repo
6. Click **"Deploy"**
7. Every time you update your GitHub file, Vercel auto-redeploys ✅

### Option C: Vercel CLI

```bash
npm install -g vercel
cd portfolio
vercel
# Follow prompts → deployed!
```

## 🌐 Custom Domain (Free on Vercel)

After deploying, you can add a custom domain:
1. Go to your project → **Settings → Domains**
2. Add your domain (e.g. `kamaleshvar.dev` or `kamaleshvard.in`)
3. Vercel gives you DNS records to add at your domain registrar
4. SSL (HTTPS) is automatic and free

Open `index.html` in any text editor (Notepad, VS Code, etc.) and find these sections:
